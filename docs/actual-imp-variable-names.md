# Actual `imp` Variable Names

## Scope

This document records the actual column names present in the prepared `imp` target. It is intended as the schema reference for test fixtures and helper assumptions.

Source used:

- `./nixr.sh "targets::tar_load(imp); cat(paste(names(imp), collapse='\n'))"`

Important current facts:

- The prepared real-data target uses `death_date`, not `death_surv_date`.
- The prepared real-data target currently contains a 5-part SHHS-2 sleep composition:
  `n1_s2`, `n2_s2`, `n3_s2`, `waso_s2`, `rem_s2`
- The prepared real-data target currently contains `R1`, `R2`, `R3`, and `R4`.
- The current test fixtures in `tests/testthat/` are aligned with these real-data names.
